# Mission（教学使命）

## 背景

Pollen Robotics 的 Microduck 双足机器人（25 cm、800 g、14 个 XL330 舵机）的
RL 训练管线已在本地 Intel Arc A380 上完整跑通（见 `docs/intel_arc_a380_guide.md`）。
现在需要让**没有机器人行业经验的软件工程师**通过这套平台学会：

- 强化学习训练机器人的完整工作流（环境 → 训练 → 曲线 → 回放）
- 读懂并安全修改一个 RL 训练环境
- 建立对 sim2real 的正确敬畏心

## 学员画像

- 软件工程师，会 Python/命令行，**不要求**机器人学/控制论/深度学习背景
- 中文母语，教程以中文为主，技术名词保留英文原文（便于查阅外部资料）
- 硬件：本机 A380（6 GB 显存），吞吐 ~3 env-steps/s（PPO 全链路实测）

## 学完能做到（判据）

1. 独立跑通四条命令（CPU 测试 / GPU 门禁 / 训练冒烟 / 渲染 GIF），并能解释
   每条命令在做什么 —— 第 1-2 课
2. 对着 `microduck_brax_env.py` 逐段说出 61 维观测、14 维动作、奖励各项的
   物理含义 —— 第 3 课
3. 设计并执行一个单变量奖励实验，预测结果，然后用数据验证预测 —— 第 4 课
4. 看到 `training_log.csv` 能判断训练健康度，遇到段错误/OOM/奖励平坦能
   定位原因 —— 第 5 课

## 课程地图

| 课 | 标题 | 类型 | 状态 |
|---|---|---|---|
| 0001 | 会走路的小鸭子是怎么炼成的 | 概念 + 测验 | ✅ |
| 0002 | 跑通你的第一条训练管线 | 实操 + 自检清单 | ✅ |
| 0003 | 解剖 61 维观测与 14 维动作 | 代码走读 + 观测探索器 | ✅ |

课程入口：`tutorials/index.html`（含结业判据与参考文档索引）。

## 约束

- 教学不改动仓库代码；所有实验以"改完跑 CPU 测试"为前置纪律
- 诚实标注本地管线与官方 sim2real 管线的差距（不许给学员"能上真机"的错觉）
