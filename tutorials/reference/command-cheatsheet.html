日常四连

# ① 代码冒烟：30 秒，不动 GPU。改了任何环境代码后必跑
JAX_PLATFORMS=cpu python3 tests/test_brax_env_cpu.py

# ② GPU 门禁：约 1 分钟，验证物理链路（期望 ~75 FPS）
python3 test_biped_mjx_batch.py 32 20 0 0

# ③ 训练冒烟：约 25 分钟挂后台（4096 步）
nohup python3 train_microduck_brax.py --num-timesteps 4096 \
    --episode-length 100 --num-evals 3 --out-dir runs/smoke \
    > runs_smoke.log 2>&1 &
tail -f runs_smoke.log

# ④ 看结果：曲线 + GIF
column -s, -t runs/smoke/training_log.csv | less -S
python3 rollout_microduck.py --replay runs/smoke/rollout_final.npz

训练时长预算（实测）

num-timesteps墙钟预期现象
4 09623 分钟管线验证；还不会走（实测 6.6→7.8 分）
10 万≈ 9 小时站得更久（第一个里程碑出现）
50 万≈ 1.9 天可能走出小碎步
300 万≈ 11 天建议挪官方 HF Jobs，别在 A380 上硬熬

公式：时长 ≈ 步数 / 3 秒 + 4 分钟（PPO 全链路实测 ~3 steps/s）

常用参数（train_microduck_brax.py）

参数默认含义 / 什么时候动它
--num-envs32并行环境数；上限 ~40（显存），减小可省内存
--episode-length250每条命最长多少步（250 = 5 s）；调小可加速 eval
--learning-rate3e-4步长；训练发散（奖励崩）时减半
--entropy-cost5e-3探索力度；行为太呆可加，太疯可减
--num-evals5中途评估次数；每次评估都花真实环境步数
--out-dir带时间戳产物目录；实验命名规范见第 4 课
