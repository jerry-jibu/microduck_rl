健康曲线长什么样

阶段一（前 1 万步）：奖励低平 —— 鸭子在学习"别乱动"
阶段二（1 万~10 万）：episode_length 率先上涨 —— 里程碑：学会不摔
阶段三（10 万+）：reward 持续爬升 —— 站稳 + 试探性迈步
阶段四（几十万+）：reward → 1.25 × episode_length —— 稳定行走并跟速

参照公式：时长 ≈ 步数 / 3 秒 + 4 分钟（本机实测）。 10 万步 ≈ 9 小时，50 万步 ≈ 1.9 天，300 万步 ≈ 11 天（该上官方 HF Jobs 了）。

本课的动手赢面：给你的训练开一次"门诊" 
# 一行抽出你那次训练的核心体征
python3 -c "
import csv
rows = list(csv.DictReader(open('runs/smoke/training_log.csv')))
prev = None
for r in rows:
    er = float(r.get('eval/episode_reward', 'nan'))
    d = '' if prev is None else f'({er-prev:+.2f})'
    print(f\"steps={r['num_steps']:>7}  reward={er:7.3f}  {d}\")
    prev = er"

判读三问：在涨吗？涨的速度对得起预算吗？ 有没有违反任何一条戒律的体征？把答案贴给老师做门诊记录。
